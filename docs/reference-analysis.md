# 参考视频与实现规则

参考：用户提供的 62.5 秒、720×1280、24 fps 视频。

- 上方是金色画框里的灰度人物画像；消除后对应区域逐渐上色。
- 下方是 19 格蜂窝棋盘，底部有 3 个待放置的色块堆。
- 色块可以放入空格；相邻同色堆聚拢，达到数量后消除，颜料飞向画像。
- 保留木质画室、立体叠片、飞行颜料、画像完成反馈。

网页版把视频未显示的具体阈值明确为：相邻同色自动合并，6 片消除；每色收集 12 片完成一幅画。提供撤销、换色、画笔救场及满盘重试。12 幅画像可直接选择体验，已完成作品本地保存。

## 开场融化（0–2.5 秒）

对原视频以 8 fps 抽取首 2.5 秒，接触表见 `reference/melt-contact.jpg`：

- 0–0.25 秒：彩色肖像开始软化，下边缘拉出圆头颜料。
- 0.25–1.1 秒：肖像向下拉长，多股颜料逐渐抵达棋盘。
- 1.1–2 秒：彩色层自上而下退去，显露灰度画像；棋盘和调色盘恢复颜色。
- 约 2 秒后：液态层收尽，开始落子。

网页采用独立 WebGL 纹理变形层，约 2.5 秒。取当前肖像的真实纹理向下拉伸，加入湿润高光和圆头滴落轮廓；蜂窝色块同步由灰度恢复颜色并轻微落定。初次打开、选择新画像和重开作品时播放。播放期间锁定落子；结束后移除覆盖层和 WebGL 资源。系统设置减少动态效果时直接进入棋盘。

网页版为艺术化近似：肖像仍使用现有灰度底稿，液态效果采用程序化纹理变形，没有加入原视频的画师角色或复制视频帧。
